为反向代理评估路径归一化差异，开发一个离线路由审计器，输入两套显式路径转换规则与请求样本。

请从空目录实现以下可运行工具。环境为 Windows、Python 3.12、仅CPU；不使用Docker或真实外部服务。除题面明确允许的cryptography外只用标准库。输入样例、模拟组件和测试数据由你在项目内构造，不存在另行提供的附件。

核心要求：
1. 规则只能选择百分号解码次数0/1/2、反斜杠是否分隔、点段折叠、大小写敏感性和尾斜杠策略；每步保留原字节到规范化字符的映射，非法UTF-8和不完整转义明确拒绝。变换按百分号解码、UTF-8解码、分隔符转换、点段折叠、大小写、尾斜杠的固定顺序进行；路径尾点保留，越过根目录拒绝。
2. 代理按规范化后的路径匹配最长前缀访问规则，后端按自己的规则定位资源；枚举有限变换组合，找出代理判为public而后端落入private的最短见证，不能以仅字符串不同代替越权证据。前缀按完整路径段匹配；最短指输入种子经过声明的有限变换后按字节长度、字节序排序的最小见证。
3. 实现见证缩减和修复建议验证：候选统一策略需消除全部已知越权，并保留正常路由集合；输出两边完整转换链与命中的规则ID。

必须覆盖的验收场景：双重编码、混合分隔符、空段、大小写与尾点组合；加入规范化不同但授权相同的反例，防止全部差异都被报为漏洞。

交付源代码、README、样例及自动化测试。提供 python -m solution --input cases.json --output result.json 和 python -m unittest discover -s tests -v 两个入口；cases.json可引用项目内源文件或二进制样例。输入输出schema、错误码及未写明的非安全性细节自行设计并完整说明，不能放宽上述要求。测试必须断言具体结果、状态或证据，不能只打印成功；固定种子可重放。所有操作局限在项目测试目录和本机模拟服务。
